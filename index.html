HORS LIGNE

À portée de clavier.

Installez SpeedType sur votre appareil pour y revenir en un geste, même sans réseau.

Sur iPhone ou iPad · Safari
  1. Ouvrez ce site dans Safari.
  2. Appuyez sur le bouton de partage □↑.
  3. Choisissez Sur l’écran d’accueil.
  4. Confirmez avec Ajouter.
Installation depuis le navigateur

Chrome ou Edge : ouvrez le menu ⋮, puis choisissez Installer SpeedType ou Installer cette application. Sur Safari macOS : Fichier → Ajouter au Dock.

Installation sur Android

Dans Chrome, ouvrez le menu ⋮ et choisissez Installer l’application ou Ajouter à l’écran d’accueil.

Le jeu et vos records fonctionnent aussi hors connexion.
